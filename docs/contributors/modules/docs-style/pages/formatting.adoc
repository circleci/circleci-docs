[#styling-text]
== Styling text

* Use **bold** for GUI menu options and button text. For example:
** Select **Org** from the sidebar
** Select **VCS** in the **Project Settings** window
** Select **Projects** from the sidebar and click **Set Up Project** for the project you want to follow

* Use italics for commonly understood technical concepts (not CircleCI features of concepts). For example:
** _Continuous Integration_
** _Concurrency_
** _Parallelism_

[#using-notes-tips-cautions-warnings]
== Using notes, tips, cautions, and warnings

The following _admonitions_ are available. Admonitions create a visual separation from the rest of the text:

* Note
* Tip
* Important
* Caution
* Warning

Use admonitions sparingly. If every paragraph is important, nothing is. Keep each one short, and if a note runs long, make it its own section.

[#when-to-use-each-type]
=== When to use each type

* `tip`: A step has an optional shortcut or efficiency hint.
* `note`: You have an important point that does not fit neatly into the flow. Also use a note when a feature is in beta or subject to change.
* `important`: Key details could lead to extra work if missed. Use this type sparingly.
* `caution`: A setting or action might have unintended consequences, or there is a security concern the reader must be aware of.
* `warning`: An action cannot be undone, such as data loss or a security breach.

[#when-not-to-use-an-admonition]
=== When not to use an admonition

* A procedure to follow to avoid future issues is a best practice. Put it in the main text.
* A known limitation that affects what the reader can expect belongs in a limitations section.

[#admonition-syntax]
=== Admonition syntax

[source,adoc]
NOTE: This is a note.

The result of this is:

NOTE: This is a note.

---

[source,adoc]
TIP: This is a tip.

The result of this is:

TIP: This is a tip.

---

[source,adoc]
CAUTION: This is a note.

The result of this is:

CAUTION: This is a note.

---

[source,adoc]
WARNING: This is a note.

The result of this is:

WARNING: This is a note.

---

You can also make a longer admonition block for any of the types listed above:

[source,adoc]
----
[NOTE]
====
This is a longer admonition with an ordered list:

. Step 1
. Step 2
. Step 3
====
----

[NOTE]
====
This is a longer admonition with an ordered list:

. Step 1
. Step 2
. Step 3
====

== Using tabs

Use tabs for showing different options:

[source,adoc]
----
[tabs]
====
Tab A::
+
--
Content for Tab A
--
Tab B::
+
--
Content for Tab B
--
====
----

Looks like:

[tabs]
====
Tab A::
+
--
Content for Tab A
--
Tab B::
+
--
Content for Tab B
--
====
