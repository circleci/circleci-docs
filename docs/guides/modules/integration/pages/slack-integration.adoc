= Slack integration
:page-platform: Cloud
:page-vcs: all
:page-plan: Free, Performance, Scale
:page-audience: developer
:page-description: Install the CircleCI Slack app and configure project-level Slack notifications for workflow status updates.
:experimental:

Use the CircleCI Slack app to receive workflow notifications in Slack. The app is installed once at the organization level and can then be configured for individual projects.

This guide explains how to:

* Install the CircleCI Slack app for your organization.
* Link a project to a Slack channel.
* Confirm which workflow events a project sends to Slack.
* Link your Slack identity to receive personal notifications.
* Approve or cancel on-hold workflows from Slack.

== Benefits

The Slack integration is the recommended way to set up workflow notifications in Slack for projects on CircleCI Cloud. It has several advantages over configuring notifications manually:

* Install the Slack app once at the organization level, then turn it on per project.
* Notifications work without changes to your CircleCI config file. You do not need to add an orb or extra steps to your pipelines.
* You do not need to create a Slack app or store OAuth tokens in a context or environment variable.
* Link projects to channels and manage notification preferences from your project settings in the web app.
* After you <<link-your-slack-identity,link your Slack identity>>, CircleCI sends workflow notifications to you directly and mentions you in the notifications for workflows you trigger.
* Approve or cancel on-hold workflows directly from a Slack notification, without opening the CircleCI web app.

== Limitations

Each Slack workspace can only be connected to one CircleCI organization at a time. This restriction is a Slack platform constraint. Slack issues a single bot token per workspace, and a new installation overwrites the existing one. If a second CircleCI organization installs the app into an already-connected workspace, it invalidates the first organization's token and breaks their integration. Connecting multiple organizations to the same Slack workspace is not supported.

If your integration is broken, an organization administrator or contributor can restore the connection by reinstalling the app from menu:Org[Slack Integration].

== Set up Slack for your organization

Organization administrators install the CircleCI Slack app once. Members with write access to a project then link that project to a Slack channel and choose which events it sends. Complete the three numbered steps in order. Then use the management controls to pause or remove the integration.

=== Prerequisites

To install the app, you need:

* CircleCI organization administrator or contributor permissions.
** If you have an organization of type `circleci`, CircleCI controls permissions. See the xref:permissions-authentication:roles-and-permissions-overview.adoc[Roles and Permissions Overview] page for more information.
** If you have an organization of type `github` or `bitbucket`, you must be an owner or member in the connected GitHub or Bitbucket organization.
+
include::ROOT:partial$tips/check-org-type.adoc[]
* Approval from a Slack Workspace Admin to install the app in your workspace. If you are not a Slack Workspace Admin, you can request approval during installation.

To link a project to a Slack channel or change its notification events, you need write permissions to the project. If you do not have them, the relevant controls are disabled in the CircleCI web app.

[#install-the-slack-app]
=== 1. Install the CircleCI Slack app

The CircleCI Slack app is installed once at the organization level and is then available to all projects in that organization.

include::ROOT:partial$app-navigation/steps-to-org-settings.adoc[]
. Select *Slack Integration* from the sidebar.
. Select **Install CircleCI Slack app**. You are redirected to Slack to authorize the app.
. In Slack, select the workspace you want to connect and select **Allow**.
+
If your workspace restricts app installations, Slack shows a **Request to Install** button instead. Submit the request. A Slack Workspace Admin must approve it before installation can complete. After approval, return to menu:Org[Slack Integration] and repeat this step to complete setup.
+
If Slack displays _This app is not approved by Slack_, continue the installation. See <<troubleshoot-slack-app-install,Troubleshoot Slack App Install>>.
. Verify that your Slack workspace appears as connected on the **Slack Integration** page.

[#troubleshoot-slack-app-install]
==== Troubleshoot Slack app install

* **Slack shows "This app is not approved by Slack."** The CircleCI Slack app is not listed in the Slack Marketplace, so Slack displays that banner for unlisted apps. Continue the install from menu:Org[Slack Integration]. To confirm you are installing the official CircleCI Slack app, check that the App ID in Slack is `A0AMHTGLKFD`.
* **Slack Marketplace links open a blank page.** The CircleCI Slack app has no public Marketplace listing, so Marketplace-style links show a blank page. Install the app from menu:Org[Slack Integration] instead.
* **Notifications stop arriving.** Check the toggle on the **Slack Integration** page and confirm it is enabled. If another CircleCI organization installed the app in the same Slack workspace, it overwrote your organization's token. Reinstall the app from menu:Org[Slack Integration]. See <<limitations,Limitations>>.

[#link-a-project-to-a-slack-channel]
=== 2. Link a project to a Slack channel

After the Slack app is installed, configure each project to send notifications to a Slack channel of your choice.

include::ROOT:partial$app-navigation/steps-to-project-settings.adoc[]
. Select *Slack Notifications* from the sidebar.
. Select **Add Slack channel**.
. Enter the Slack channel name or channel ID.
+
* **Public channel:** Enter the channel name or the channel ID.
* **Private channel:** First, run `/invite @CircleCI` in the channel to invite the CircleCI bot. Then, enter the channel ID. If you save before inviting the bot, you receive an error.
+
To find a channel ID, open the channel in Slack and select the *Open channel details* option from the channel menu. The channel ID is displayed in the modal.
. Confirm that the channel ID appears under **Slack channel ID**.

To update the channel, select the edit icon icon:edit-solid[Edit icon] next to the channel ID. To remove it, select the delete icon icon:delete[Delete icon].

When you save a channel configuration, CircleCI posts a welcome message from the CircleCI bot to the configured channel. The message includes your project name and confirms the connection is working. If you add the same Slack channel to multiple projects, CircleCI sends one welcome message per project.

=== 3. Confirm notification events

Events control which workflow activity CircleCI posts to a project's Slack channel. When you first configure a channel, CircleCI enables notifications for failed workflows on the default branch. Changes save automatically and apply to subsequent workflow activity for that project.

. Select *Slack Notifications* from the sidebar.
. Scroll to *Events*.
. Expand the **Workflow Completed** category.
. Confirm that **On default branch (failed, error, unauthorized)** is enabled. Select or clear an option to change it.

=== Manage the Slack integration

Organization administrators and contributors can pause or remove the Slack integration from menu:Org[Slack Integration] using two controls:

* **Toggle:** Enable or disable the Slack integration for the entire organization. Disable the integration to pause notifications for all projects. Individual project settings are preserved and resume when you re-enable the integration.
* **Delete:** Select the delete icon icon:delete[Delete icon] to remove the CircleCI Slack app from the workspace. This stops all Slack notifications for all projects in the organization.
+
WARNING: Deleting the Slack app stops all project notifications across the organization. You must reinstall the app to resume notifications.

== Use Slack with your own account

After your organization installs the CircleCI Slack app, you can link your Slack identity to receive personal notifications and approve workflows from Slack. If the app is not installed yet, see <<install-the-slack-app,Install the CircleCI Slack App>>.

[#link-your-slack-identity]
=== Link your Slack identity

Linking your Slack identity connects your CircleCI user account to your identity in a Slack workspace that has the CircleCI Slack app installed. This enables direct message notifications, tagging in notifications, and approving a held workflow directly from Slack. Linking is optional.

Each Slack identity link applies to a single Slack workspace. If you belong to multiple organizations that each have their own connected Slack workspace, link your identity separately for each one. A Slack identity can be linked to only one CircleCI user account at a time.

==== Connect your Slack identity

include::ROOT:partial$app-navigation/steps-to-user-settings.adoc[]
. Select link:https://app.circleci.com/settings/user[Account Integrations] from the sidebar.
. In the *Slack* section, find the organization you want to link and select btn:[Connect].
. In Slack, confirm you are signed in to the account you want to link and select btn:[Allow].
+
If you previously signed in to this Slack workspace with Sign in with Slack, Slack may skip this confirmation and link your identity automatically.
. Confirm that the workspace now shows as connected on the *Account Integrations* page.

You can also link your identity from menu:User Settings[Notifications]. Select link:https://app.circleci.com/settings/user/notifications[Notifications] from the sidebar, find your organization in the table, and select btn:[Connect] in the Slack column.

==== Disconnect your Slack identity

To stop personal Slack notifications, select btn:[Disconnect] next to the linked workspace on either the *Account Integrations* page or the *Notifications* page in User Settings.

==== How Slack identity linking works

CircleCI uses link:https://docs.slack.dev/authentication/sign-in-with-slack/[Sign in with Slack] to link your identity. Sign in with Slack is Slack's own implementation of OpenID Connect (OIDC), a standard built on top of OAuth 2.0.

During the exchange, Slack returns an ID token containing your Slack user ID, team ID, and display name. CircleCI reads these identity claims to create the link between your CircleCI user and your Slack identity. CircleCI does not retain the Slack access token or ID token from the exchange.

==== Troubleshoot Slack identity linking

* **The link fails after you select Allow in Slack.** Your Slack workspace or organization may have Sign in with Slack disabled, or may require admin approval for apps that request the Sign in with Slack identity scope. A Slack workspace admin can confirm or enable Sign in with Slack from **Admin** > **Apps and workflows** > **App Management Settings** in Slack. If your company sets an Apps organization policy at the Slack org level, an Org Owner may also need to approve the CircleCI app. Try linking again afterward.
* **CircleCI shows a "Slack account already linked" error.** The Slack identity you authenticated with is already connected to a different CircleCI account. Sign in to that account and unlink the Slack identity before linking it here.
* **The Connect button is unavailable or shows "Slack not installed."** An organization administrator or contributor must install the CircleCI Slack app before you can link your identity. If your Slack workspace restricts app installations, a Slack Workspace Admin must approve the installation. See <<install-the-slack-app,Install the CircleCI Slack App>>.

[#receive-dms-for-workflows-you-trigger]
=== Receive DMs for workflows you trigger

When you link your Slack identity, CircleCI delivers your xref:integration:notifications.adoc#my-work[My Work] notifications as Slack direct messages. You can set different status filters for Slack and email. This includes xref:integration:notifications.adoc#approval-job-notifications[Approval Job Notifications] for workflows you trigger.

Update your preferences in menu:User Settings[Notifications].

=== Get tagged in notifications

When you link your Slack identity, CircleCI tags you in a project's Slack notifications for workflows you trigger. The notification shows your Slack tag followed by your VCS username. If you have not linked your identity, the notification shows your name followed by your VCS username instead, with a link to connect your Slack account.

[#approve-or-cancel-workflows-from-slack]
=== Approve or cancel workflows from Slack

When a workflow goes on hold at an approval job, the Slack notification includes btn:[Approve] and btn:[Cancel] buttons. Use these buttons to act on the workflow without opening the CircleCI web app. Selecting a button opens a confirmation dialog before the action runs. The buttons appear in both project channel notifications and direct messages.

To use the buttons, link your Slack identity first and have the same permissions you need to approve or cancel a workflow in the CircleCI web app. For more information on approval jobs, see the xref:orchestrate:workflows.adoc#holding-a-workflow-for-a-manual-approval[Hold a Workflow for a Manual Approval] section.
