[TIP]
====
Run the `circleci testsuite` CLI tooling from the directory where your tests are located. That directory is typically your repository root, but for monorepos it can be the root of a subpackage (for example, `cd service-1 && circleci testsuite run "ci tests"`).

The testsuite looks for the `.circleci/test-suites.yml` configuration file, and detects your test runner, in the repository root or the subpackage where you run the CLI. All commands (`discover`, `run`, `analysis`) execute relative to where you run the CLI, so avoid using `cd` or `--directory` flags within your commands.
====
