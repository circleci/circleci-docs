To find out your organization type, check your organization slug at menu:Org[Overview]. `github` and `bitbucket` type organizations are OAuth authenticated orgs. The slug format depends on the type:

* `github` type: `github/<your-org-name>` or `gh/<your-org-name>`
* `bitbucket` type: `bitbucket/<your-org-name>` or `bb/<your-org-name>`
* `circleci` type: `circleci/<UID>`
