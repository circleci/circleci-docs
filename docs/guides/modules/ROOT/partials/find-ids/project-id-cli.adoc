To return the project ID for the current repository:
+
[source,console]
----
$ circleci project get --json --jq '.id'
----
+
To look up a specific project by slug, replace `<project-slug>` with your project slug. You can find the slug in menu:Project Settings[Overview].
+
[source,console]
----
$ circleci project list --slug <project-slug> --json --jq '.[0].id'
----
