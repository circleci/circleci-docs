* Defined your test suite in `.circleci/test-suites.yml`. This feature does not work with the built-in test suite, because it needs options that only the file can set. To create the file, run `circleci testsuite generate "ci tests"`, which writes the test suite that `circleci testsuite` detects. You can also ask your AI coding agent to set it up with the `circleci-testsuite` skill from xref:guides:toolkit:circleci-agent-skills.adoc[CircleCI Agent Skills]. See xref:reference:ROOT:testsuite-configuration-reference.adoc#zero-config[Run Without a Configuration File].
