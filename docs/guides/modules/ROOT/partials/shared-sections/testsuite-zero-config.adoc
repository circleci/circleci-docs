`circleci testsuite run` runs your tests with a built-in test suite for your test runner, and uploads the test results. Name your test runner with the `--runner` flag, or leave the flag out to detect your test runner from your project files. To change how your tests run, or if `circleci testsuite` cannot detect your test runner, add a `.circleci/test-suites.yml` file. For more information, see xref:guides:test:getting-started-with-smarter-testing.adoc[Getting Started With Smarter Testing].
