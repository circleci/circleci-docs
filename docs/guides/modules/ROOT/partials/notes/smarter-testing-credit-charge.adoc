NOTE: Test impact analysis, dynamic test splitting, dynamic parallelism, and auto rerun failed tests count test atoms toward your plan's monthly allowance. Each `circleci testsuite run` with one or more of these capabilities enabled counts its discovered test atoms once, whatever the job's parallelism. If a job runs more than one test suite, each run counts separately. Overall usage above your plan's allowance has a credit charge of 3,000 credits per 100,000 test atoms.
